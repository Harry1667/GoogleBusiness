# GoogleBusiness

智簡 Zhi Jian 低門檻子專案 — 以 Google 商家代管為信任入口，將小店家從 NT$2,000 一次性服務逐步升級至智簡月費顧問方案。

## 服務層級
| 級別 | 服務 | 收費 |
|------|------|------|
| L1 | Google 商家建檔與優化 | 2,000–5,000（一次性）|
| L2 | 月代管（持續優化 + 評論回覆） | 1,500–3,000 / 月 |
| L3 | 加值服務（網站 / LINE 官帳 / 廣告） | 依需求報價 |

## 漏斗位置
```
本專案（低門檻入口）  →  智簡（高階月費顧問）
L1 建檔 2,000          →
L2 月代管 3,000        →  標準駐點 200,000 / 月
L3 加值                →  深度整合 300,000 / 月
```
