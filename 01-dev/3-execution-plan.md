# 商家代管事業｜計畫書 + 任務細部執行手冊

> **核心原則**：業務先行，工具當槓桿。**沒成交 3 家不寫工具**。
>
> **第一個月目標**：8 家一次性建檔 + 5 家月代管簽約 → NT$ 30,000
>
> **第三個月目標**：累積 20 家月代管 → 月入 NT$ 50,000+（被動）

# 第一部分：總覽計畫書

## 0. 兩條軸線並行

```
業務軸：找客 → 拜訪 → 成交 → 交付 → 月代管 → 轉介紹
工具軸：手動跑通 → MVP 工具 → 部署上線 → 規模化自動化
```

**鐵律**：業務軸永遠優先。工具軸卡住就先放著，業務不能停。

# 第二部分：每一步詳細執行手冊

## A. 前置準備細節

### A1｜註冊業務專用 Gmail（0.2h，⭐）
**具體做什麼**
1. 開 incognito → 註冊 `yourname.gbp@gmail.com`（名稱越像「正規服務」越好）
2. 設定大頭貼（西裝照或 Logo）、簽名檔（姓名 + LINE ID + 服務範圍）
3. 開啟兩步驟驗證

**可能遇到的困難**
- Gmail 要求手機號驗證 → 用本人號碼即可，不要用免洗號（之後會被停權）

**為什麼要做**
- 客戶之後要在他自己的 Google 商家後台「新增使用者」，加你這個 Gmail 為「經理人」。**永遠不要直接登入客戶帳號**（這是商業紅線）。

---

### A2｜LINE 官方帳號 + 電子名片（1h，⭐）
**具體做什麼**
1. LINE Official Account Manager 申請免費版（200 則 / 月）
2. 設定大頭貼、自我介紹、加好友歡迎訊息（範例：「您好！我是 OO，專門協助店家經營 Google 商家。免費諮詢請傳『諮詢』」）
3. 用 Canva 做一張電子名片（手機豎版尺寸 1080×1920），寫姓名、LINE QR、服務項目、價格錨點

**可能遇到的困難**
- LINE 官方帳號審核要 1–2 天 → 同步先用個人 LINE 接單，不要等
- 200 則 / 月很容易爆 → 一開始用就好，超過 30 客再升級

---

### A3｜用 AI 跑通完整建檔流程（4h，⭐⭐⭐）
**具體做什麼**
- 拿一家虛擬店（例如「巷口阿明牛肉麵」），完整跑一次：
  1. 用 Claude 寫商家簡介（3 個版本：活潑 / 專業 / 在地）
  2. 用 Photoroom / Canva AI 修一張爛照片（去雜物、調光）
  3. 用 Claude 寫 4 篇貼文（活動 / 產品 / 在地 / CTA）
  4. 用 Claude 寫 3 種評論回覆模板（5 星 / 4 星 / 1 星）

**可能遇到的困難**
- AI 寫出來太「網紅口吻」、不像在地店家 → Prompt 要明確指定「台灣中南部小店、口語、不要 emoji 海」
- Photoroom 去背把招牌也吃掉 → 改用 Canva Magic Eraser 點選保留

**產出**
- 一份「完整建檔範本包」存到 Notion，之後每接一家照樣搬

---

### A4｜找 2 家朋友店免費試做（8h，⭐⭐⭐）
**具體做什麼**
- 條件：朋友的店、有實體、現有 GBP 沒在經營
- 跑完整 D1–D7 流程
- 拍 Before / After 對比截圖（GBP 主頁 + 照片牆 + 商品頁）

**可能遇到的困難**
- 朋友覺得不好意思一直配合 → 講清楚「我這是練功，反正你也沒在弄」
- 朋友店根本沒爛照片可改 → 換一家，找真的「荒廢型」店家
- Google 驗證要等明信片 7–14 天 → 先做能做的（簡介、貼文），驗證在跑

**產出**
- 5–10 組 Before/After 截圖，存手機相簿命名為 `demo_店名_前/後`

---

### A5｜100 家潛在客戶試算表（2h，⭐⭐）
**具體做什麼**
- Google Sheet 欄位：店名 / 地址 / 類別 / 照片數 / 評論數 / 評分 / 回覆率 / 痛點分數 / 接觸狀態
- 鎖定範圍：住處 / 學校周邊 1km，餐飲 + 機車行 + 小賣店
- 用 Maps 列表抓 → 一家一家填欄位
- 痛點分數公式：照片<5 +30 / 評論<30 +20 / 3 個月無更新 +20 / 評分 3.8–4.5 +15 / 無網站 +10

**可能遇到的困難**
- 手動抓 100 家很慢（2h 不夠）→ 第一週只填 30 家，邊拜訪邊補
- 「最近更新時間」Maps 不會直接顯示 → 看最近一則貼文 / 評論回覆時間

**升級路徑**：未來這個欄位由 E1 客戶雷達自動填

---

### A6｜背熟話術（3h，⭐⭐⭐）
**具體做什麼**
- 三段式話術逐字稿寫在小卡，每天朗讀 3 次
- 找朋友角色扮演老闆，演 4 種類型（鐵齒 / 殺價 / 拖延 / 多疑）
- 每種類型練 3 輪到能脫口而出

**可能遇到的困難**
- 演練覺得很尬 → 對著鏡子練、錄音回放找卡頓處
- 真的進場還是會緊張 → 第一週只當「市場調查」，問三個問題就走（「老闆你 GBP 後台還有在用嗎」）建立心理閾值

## B. 業務執行細節

### B1｜每天陌生拜訪 5 家（3h/天，⭐⭐⭐⭐）
**具體做什麼**
- 黃金時段：餐飲 14:00–16:30、機車行 / 小賣店 10:00–11:30
- 每家流程：消費（30 元起）→ 讚美具體品項 → 滑手機展示痛點 → 三段式話術
- 每家結束立即在隨身包記錄：成交 / 拒絕 / 再訪

**可能遇到的困難**
- 老闆很忙不理你 → 留名片 + 一句「我下週再來」就走，不要硬聊
- 進場張口就被當推銷員 → 永遠**先消費 30 元**再開口
- 連續被拒受打擊 → 設「5 拒就回家」上限，**拒絕是統計學問題不是個人問題**

**KPI**：第一週成交率可能只有 5%，第三週要拉到 20%

---

### B2｜現場成交 + 收訂金（0.5h/家，⭐⭐⭐⭐⭐）
**具體做什麼**
1. 老闆說「好啊」→ 立即拿手機打開 LINE 同意書範本
2. 改名稱、方案、金額 → 截圖存證 → 老闆 LINE 給你「同意」兩個字
3. 開 LINE Pay / 街口 QR → 收 50% 訂金當場到帳
4. 加老闆 LINE → 約交付日

**可能遇到的困難**
- 老闆說「明天再付」→ **絕對不要走**，講「沒關係我等你 5 分鐘，這樣我今天就能開始」
- 老闆要刷卡 → 用街口 / LINE Pay 信用卡綁定，現場開
- 老闆要求「做完再付」→ 退一步說「先付 30%，做完付剩下，這樣我們都安心」

**鐵律**：離店前沒收到錢，這單就是 50% 死單

---

### B3｜D1–D7 後台建檔交付（5h/家，⭐⭐⭐）
**具體做什麼**（嚴格按 9-talk.md 第 6 節 D1–D7 表）
- D1：開 / 認領 GBP + 送驗證 + 收老闆素材（30+20 分）
- D2：照片批次優化 + 商家簡介（1h+15 分）
- D3：商品 / 菜單建檔（1h）
- D4：等驗證 / 補資料
- D5：4 週貼文排程 + 評論回覆模板（1h+20 分）
- D6：自檢
- D7：交付會議

**可能遇到的困難**
- GBP 驗證一直不過（明信片 30 天才到） → 改用「影片驗證」（手機錄走進店、招牌、收銀台 30 秒）
- 老闆給的照片太爛 / 太少 → 排一次 30 分到店現場拍 20 張（手機就夠）
- 老闆改密碼後沒給你經理人權限 → 提早 D1 就把「請新增 OO@gmail.com 為經理人」的截圖步驟發 LINE

---

### B4｜交付會議 + 提案月代管（0.5h/家，⭐⭐⭐⭐）
**具體做什麼**
1. 到店 → 手機 Google 搜店名 → 給老闆親眼看
2. 滑照片牆 / 商品頁 / 貼文（一項講 30 秒）
3. 後台秀「初始曝光數」（哪怕 50 次）
4. **只教 1 件事**：怎麼用手機 App 回評論
5. 直接遞月代管提案：「Google 演算法是『有人持續更新才會推』，停下來就掉。我每月 4 篇貼文 + 評論 + 月報，2,000 / 月，要不要直接接著做？」
6. 當場簽 LINE 月初轉帳 / LINE Pay 訂閱

**可能遇到的困難**
- 老闆說「我自己來就好」→ 「OK 沒問題，給你一個月試試，覺得太忙隨時找我」（留種子）
- 老闆說「下個月再說」→ 「下個月可以，但這個月停了演算法會掉，要不要先做這個月就好？500」（拆小單）

**黃金法則**：80% 的月代管要在這天簽下來

---

### B5｜月代管月度執行（1h/月/家，⭐⭐）
**具體做什麼**（每週 15 分）
- W1：發貼文 #1（月度主題） + 回評論
- W2：發貼文 #2（產品） + 回評論
- W3：發貼文 #3（在地連結） + 回評論
- W4：發貼文 #4（CTA） + 月報

**可能遇到的困難**
- 一個月超過 10 家後手忙腳亂 → 用 D1（批次貼文）月初一次跑完 30 家 × 4 篇
- 老闆中途要插播臨時活動 → 收 NT$ 300/篇 加值費（不要做白工）

---

### B6｜月報撰寫推送（0.5h/家，⭐⭐）
**具體做什麼**
- 套 9-talk.md 第 8 節月報模板
- 截圖 GBP 後台「成效」頁（曝光 / 路線 / 電話）
- LINE 直接傳給老闆，附一句「老闆有任何想推的活動隨時跟我說 🙌」

**可能遇到的困難**
- 月報數據掉了 → **誠實寫出來** + 解釋原因（「上月節慶結束」），給下月改善計劃
- 老闆已讀不回 → 月底再丟一次「方便這週末約見面 5 分鐘嗎」維持接觸

---

### B7｜索取轉介紹（0.2h/家，⭐⭐⭐）
**具體做什麼**
- 時機 1：交付會議當天（情緒最高點）
- 時機 2：第一份月報送出時
- 話術：「老闆，旁邊那間 OO 我看也是同樣狀況，你引薦的話我給他八折，順便送你下個月免費」

**可能遇到的困難**
- 老闆說「好啊我問問」然後就沒下文 → 一週後傳「上次聊到的 OO 老闆，方便給我電話我自己接觸嗎」
- 老闆保護同行 → 改問「你常去的店裡有覺得 GBP 弄很爛的嗎」（消費者角度）

## C. 工具開發 — Milestone 1 細節

### C1｜業務隨身包 PWA（8h，⭐⭐⭐）
**具體做什麼**
- 技術棧：Next.js 14 App Router + Tailwind + shadcn/ui + Service Worker（PWA）
- 6 個頁面：話術 / Demo 圖庫 / 報價計算機 / 同意書產生器 / 拜訪紀錄 / 異議速查
- 資料：第一版用 JSON 寫死在前端，IndexedDB 存拜訪紀錄
- 部署：Vercel 暫時免費版 → 之後搬到 Oracle

**可能遇到的困難**
- PWA 在 iOS Safari 的 Service Worker 行為不一致 → 第一版只支援 Android Chrome（自己用就好）
- 離線圖片快取爆掉 → Demo 圖壓到 200KB 以下、總共 < 20 張
- 同意書 LINE 分享按鈕在 PWA 內叫不起來 → 用 `navigator.share()` API + 退路用「複製到剪貼簿 + 提示貼到 LINE」

**驗收**
- 從進店到滑出 Demo < 5 秒
- 完全離線可用（除分享外）

---

### C2｜客戶 CRM 極簡版（12h，⭐⭐⭐）
**具體做什麼**
- 技術棧：Next.js + Postgres（Docker）+ Prisma + Basic Auth
- Schema：Client / Service / Payment / Note 四張表
- 4 個視圖：今日待辦 / 客戶列表 / 客戶詳情 / 本月收入
- 收款提醒：cron 每天 9 點掃「next_billing_date < today + 3」

**可能遇到的困難**
- 設計 Schema 過早抽象（想做多店、多服務、多層權限）→ **第一版只給自己用，所有欄位扁平**
- Postgres Docker 跑在 Mac 開發環境 vs Oracle 線上版本不同步 → 用同一份 docker-compose.yml，本機 + 線上都用
- Basic Auth 在手機很煩 → cookie 設 30 天

**驗收**
- 新增一個客戶 < 1 分鐘
- 今日待辦頁打開 < 1 秒

---

### C3｜AI 內容工廠 v1（16h，⭐⭐⭐⭐）
**具體做什麼**
- 技術棧：Next.js API Route + Anthropic SDK + 自架 Postgres 存 Prompt
- 兩個功能：
  1. 商家簡介產生器：輸入店名 + 業種 + 3 關鍵字 → 出 3 版
  2. 評論回覆助手：貼評論 + 選店家 → 出 3 種語氣
- Prompt 寫 YAML，方便調整
- 模型：Opus 4.6 寫長文、Haiku 4.5 跑量
- 加快取：相同輸入 24 小時內直接讀 cache
- Prompt Caching：用 Anthropic 的 cache_control 把店家品牌語氣寫在 system，省 90% token

**可能遇到的困難**
- 月成本爆炸（30 客 × 4 篇 + 評論 = 上百次呼叫）→ 一定要開 Prompt Caching、跑量用 Haiku、設月預算上限
- AI 寫出來像 ChatGPT 罐頭味 → Few-shot prompt 給 5 個你自己寫的好範本
- 不同店家品牌語氣混在一起 → CRM 客戶資料加 `brand_voice` 欄位（活潑 / 專業 / 親民），呼叫時帶入

**驗收**
- 評論回覆 < 5 秒
- 月 API 成本 < NT$ 500（30 客戶規模）

## D. 工具開發 — Milestone 2 細節

### D1｜批次貼文生成（8h，⭐⭐⭐⭐）
**具體做什麼**

- 一鍵匯出 CSV / 直接寫進 GBP 排程（如果 GBP API 通了）

**可能遇到的困難**
- 同時打 30+ 次 API 被 rate limit → 用 Anthropic SDK 的 batch API 或自己排隊（5 並發）

- 沒辦法直接排程進 GBP（API 限制） → 第一版只輸出 CSV，手動貼到 GBP App

**驗收**：10 家 × 4 篇 < 3 分鐘

### D2｜今日待辦 Dashboard（4h，⭐⭐⭐）

## E. 工具開發 — Milestone 3–5 細節（後期再展開）

### E1｜客戶雷達（20h，⭐⭐⭐⭐⭐）
**為什麼難**：Google Places API 有 ToS（不能存超過 30 天）+ 計費門檻 + 痛點打分要驗證
**具體做**：先做 MVP（單一查詢區域），等 50 家驗證後再擴大
**困難 + 對策**：
- API 太貴 → 限制單次掃 200m 半徑、加 Redis 快取 24h
- ToS 違規風險 → 只存「該店家 ID」+ 痛點分數，不存照片 / 評論原文

### E3｜GBP API 申請（4h + 等審）
**為什麼難**：Google 要驗證你是「正當代管服務」，要填詳細的服務說明
**具體做**：填 Google Business Profile API 申請表 + 附上你的服務頁面 URL（**所以官網要先有**）
**困難 + 對策**：
- 被拒 → fallback 到「老闆給後台權限後手動截圖 + Claude Vision OCR」
- 審核要 2–8 週 → 不要等，先用 fallback 跑

### E4｜月報生成器（16h，⭐⭐⭐⭐⭐）
**為什麼難**：要整合 GBP API + AI 寫稿 + 圖卡生成 + LINE 推送
**MVP 路徑**：先做純 AI 文字版（5h），確定老闆愛看再做圖卡（11h）

### F1｜KPI 週檢討（1h/週，⭐）
**具體做什麼**
